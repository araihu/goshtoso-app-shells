# Changelog

## [v0.1.9] - 2026-10-30

### Added

- `componentdocshell.Navigation.GlobalLinks` and `GlobalLabel` compose site-wide destinations with contextual documentation navigation. `DisableLocalNavigation` removes the desktop rail while retaining global links in the mobile drawer.
- `componentdocshell.Config.HeaderNavigation` accepts consumer-owned centered header navigation while preserving the shell's responsive branding and controls.
- Console shells support drawer menus and social metadata.

### Fixed

- Documentation sidebar navigation keeps its scroll container and position throughout HTMX swaps. Direct loads and navigation reveal an active item only when it is outside the sidebar viewport.
- Footnote links and backlinks scroll within the documentation content region and preserve the persistent header.
- Console color mode follows system preference changes while the user has no explicit override.
- Shell providers register before Alpine initializes; short console pages keep the footer at the bottom of the content region.

### Dependencies and tooling

- Require templ v0.3.1100 and Goshtoso v0.4.6, with checked-in templates generated by the matching templ compiler.
- Require Go 1.27.3 and use Dagger v0.21.11 in CI. Draft, external, and non-allowlisted pull requests use GitHub-hosted runners.
- Refresh embedded Arai Hû theme and brand fallbacks from Assets v0.2.6.

### Upgrading

- Upgrade this module and the application's templ runtime and compiler together, then regenerate only the application's own `.templ` files. Do not regenerate dependency code in the module cache.
- When passing native event handlers through `templ.Attributes`, use `templ.JSFuncCall` for calls or `templ.JSUnsafeFuncCall` for trusted application-authored JavaScript. The new runtime sanitizes plain string handlers.
- Continue serving the shell assets from the updated module so the HTML and sidebar navigation runtime remain in sync.
- Use keyed configuration literals. New optional configuration fields preserve zero-value behavior but cannot preserve external positional struct literals.
